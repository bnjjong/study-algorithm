# 1. Two Sum

- 난이도: **Easy**
- 링크: https://leetcode.com/problems/two-sum/
- 주제: 배열, 해시맵

## 문제

정수 배열 `nums`와 정수 `target`이 주어집니다.
합이 `target`이 되는 **두 원소의 인덱스**를 배열로 반환하세요.

- 정답은 **항상 유일하게 존재**한다고 가정합니다.
- 같은 원소를 두 번 사용할 수 없습니다 (서로 다른 인덱스 두 개여야 함).
- 반환하는 인덱스 순서는 상관없습니다.

## 예시

```
입력: nums = [2, 7, 11, 15], target = 9
출력: [0, 1]
설명: nums[0] + nums[1] == 2 + 7 == 9

입력: nums = [3, 2, 4], target = 6
출력: [1, 2]

입력: nums = [3, 3], target = 6
출력: [0, 1]
```

## 제약 조건

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 정답이 존재하는 입력만 주어집니다.
